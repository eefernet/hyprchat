# Image Generation Setup

Image generation is optional. HyprChat starts and serves chat normally when
`COMFYUI_URL` is empty. Configure ComfyUI only when you want Image Studio,
persona photos, or the chat `generate_image` tool.

## Existing ComfyUI

Use this path when you already have a ComfyUI instance.

1. Start ComfyUI with its HTTP API reachable from the HyprChat server.

   ```bash
   cd /opt/comfyui
   ./venv/bin/python main.py --listen 0.0.0.0 --port 8188
   ```

2. Install at least one checkpoint under ComfyUI's `models/checkpoints/`.

   The embedded HyprChat fallback workflow is a standard SDXL text-to-image
   graph whose checkpoint field is `sd_xl_base_1.0.safetensors`. Either place
   that checkpoint in ComfyUI or choose another checkpoint in Image Studio and
   save it as the default for chat generation.

3. Point HyprChat at ComfyUI.

   Server install:

   ```bash
   sudoedit /opt/hyprchat/.env
   # COMFYUI_URL=http://<comfy-host>:8188
   sudo systemctl restart hyprchat
   ```

   Runtime UI:

   ```text
   Settings -> Connections -> ComfyUI
   ```

4. Verify the connection.

   ```bash
   curl http://<comfy-host>:8188/system_stats
   curl http://<comfy-host>:8188/object_info/CheckpointLoaderSimple
   curl -s http://<hyprchat-host>:8000/api/images/checkpoints | python3 -m json.tool
   ```

## Default Workflow Requirements

HyprChat submits ComfyUI API-format workflows. UI-format workflow JSON is not
directly executable by ComfyUI's `/prompt` endpoint.

Valid options:

- Use the built-in SDXL workflow and a checkpoint ComfyUI can resolve.
- Set `COMFYUI_WORKFLOW_PATH` to an API-format JSON file on the HyprChat server.
- Upload an API-format JSON workflow in Image Studio and save it in the workflow library.
- Upload a PNG generated by ComfyUI that contains embedded API workflow metadata.

For Flux, v-prediction, Flow Matching, or custom graph families, save
per-checkpoint defaults in Image Studio so the chat `generate_image` tool uses
the expected sampler, scheduler, CFG, steps, prompt prefix, negative prefix, and
model-sampling mode.

## Proxmox Companion LXC

This repo includes a homelab helper for creating a companion ComfyUI and voice
container:

```bash
bash scripts/create-comfyui-lxc.sh 115 192.168.1.115
```

Run it on the Proxmox host. It prints the second-phase commands to run inside
the new LXC, including NVIDIA userspace libraries, ComfyUI, the SDXL base
checkpoint, a systemd unit, optional voice services, and verification curls.

This script is a reference setup for the documented homelab. It is not required
for a normal VM, workstation, or existing ComfyUI install.

## Optional HyprChat ComfyUI Control Node

Vanilla ComfyUI can generate images without this node. Installing it enables:

- `/hyprchat/free` for explicit model unload.
- `/hyprchat/memory` for memory status in Image Studio.
- `/hyprchat/restart` for ComfyUI restart from HyprChat.
- `/hyprchat/cleanup` so HyprChat can delete ComfyUI output/history copies
  after it has downloaded the generated image.
- Idle model unload through `HYPRCHAT_COMFY_IDLE_UNLOAD_SECONDS`.

Install inside the ComfyUI environment:

```bash
scp scripts/comfyui_hyprchat_cleanup.py root@<comfy-host>:/opt/comfyui/custom_nodes/
ssh root@<comfy-host> 'systemctl restart comfyui'
ssh root@<comfy-host> 'journalctl -u comfyui -n 80 --no-pager | grep "HyprChat ComfyUI" || true'
```

Useful systemd environment values for the ComfyUI unit:

```ini
Environment=HYPRCHAT_COMFY_IDLE_UNLOAD_SECONDS=300
Environment=HYPRCHAT_COMFY_WATCH_INTERVAL_SECONDS=10
Environment="HYPRCHAT_COMFY_RESTART_COMMAND=systemctl restart comfyui"
```

## Journal Scrub Helper

HyprChat's Image Studio "Delete all" purge removes HyprChat image files and
database references. With the optional ComfyUI control node it can also remove
ComfyUI output/history copies. It cannot directly vacuum systemd journals while
the app runs as the unprivileged `hyprchat` user.

Install the root-owned journal scrub helper on the HyprChat server if you want
the purge endpoint to trigger journald rotation/vacuum:

```bash
sudo bash scripts/install-journal-scrub.sh
```

## Verification Checklist

After configuring ComfyUI:

1. `GET /api/health` shows `services.comfyui.status` as `ok` or `degraded`.
2. `GET /api/images/checkpoints` returns at least one checkpoint name.
3. Prompt enhancement in Image Studio returns an enhanced prompt. This checks
   the model provider path, not ComfyUI itself.
4. One Image Studio generation completes and returns an image artifact.
5. One chat request that asks for an image causes the model to call
   `generate_image` and renders the generated image inline.
